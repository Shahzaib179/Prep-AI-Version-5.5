# v5.1: UI/UX redesign

Inspired by the layout principles of a modern student dashboard (sidebar, top bar, daily goal card, schedule, score gauge, subject strengths, quick-access cards), with Prep AI's own identity: burgundy `#92002D`, page `#F8F3F5`, white cards, text `#182B49`, muted `#718096`, borders `#E8E1E5`, Inter with system fallback.

## What changed
| Area | Change | Files |
|---|---|---|
| Design system | CSS variables (colour tokens) + component styles for buttons, inputs, tabs, metrics, expanders, alerts, uploader, chat, tables, answer-option cards; light brand theme by default, student colour themes (Dark, Sepia...) still work | `styles.py`, `theme.py`, `.streamlit/config.toml` |
| Shell | Grouped sidebar (Main, Learning, Classes, AI tools, Planning, My account) with icons and highlighted active page; goal card; top bar with breadcrumb, real streak/level and the student; works as Streamlit's off-canvas drawer on phones | `navigation.py`, `ui_kit.py`, `app.py` |

## Data honesty
- **Checklist:** "Answer N questions", "Daily Challenge", "Retake mistakes", "Revise due topics" and assignments are completed by actually doing them (read from stored activity). Study-plan sessions for today (from the saved plan, Day 1 = day it was created) are tick boxes saved in `daily_tasks`.
- **Schedule:** only real plan sessions and real assignment deadlines. Otherwise an empty state with a "Create a study plan" button.
- **Score estimate:** Prep AI had no score predictor, so this is a practice-based estimate: accuracy over answered questions scaled to 180, with an 80% (Wilson) range that narrows as answers grow. Shown only after 20 answered questions (`config.SCORE_MIN_ANSWERS`), always labelled "not an official MDCAT prediction".
- **Strengths:** subject rings use the existing topic mastery; no data shows a grey ring and an en dash, never 0%. Logical Reasoning appears only if the student has such data.
- Names and exam targets come from the account; no hard-coded sample values.

## Not changed
AI agents, prompts, RAG/FAISS, document pipeline, quiz generation and marking, mastery maths, accounts, classes, assignments, live quiz, tutor tools, deployment.

## Run and test
`streamlit run app.py`. Tests: every `tests/test_*.py` with `python -m unittest tests.<name>`, plus `python tests/app_pages_smoke.py`, `python tests/ui_smoke.py`, `python tests/perf_probe.py`. UI preview without Streamlit: `python scripts/preview_ui.py out_dir` (writes HTML and PNG screenshots at desktop, tablet and phone widths).
