# v5.6: search bar, mock tests are not performance, sidebar and schedule fixes

## Upgrade from v5.5
Copy the files over v5.5 and start the app. Migration 15 runs once and mastery is recomputed once (`MASTERY_MODEL_VERSION` = 3). No new packages.

## Changes
- **Sidebar**: every descendant of a nav button is now start-aligned (Streamlit centres button content through several nested wrappers), with auto margins as a second guard and a fixed 1.5rem icon column. Needs a check in the real app.
- **Today's Schedule**: no line through finished titles (the title is only dimmed); the icon chip, its background and any pseudo-elements around the icon are removed.
- **Search bar** (top bar, `global_search`): `search.py` finds pages (by name and keywords) and the signed-in user's own content. Students: mistakes, classes, assignments, quiz history. Tutors: classes, question bank. Each result has an Open button; opening clears the box. Results never include another user's data.
- **Mock tests are not performance**: `record_quiz(..., count_in_stats=False)` for mock quizzes. The attempt, XP, streak, mock history and Mistakes Diary entries are kept; the score estimate, mastery, strengths/weaknesses, History and tutor averages ignore it. Migration 15 adds `in_stats` to `quiz_attempts` / `question_attempts` and flags existing mock attempts.
