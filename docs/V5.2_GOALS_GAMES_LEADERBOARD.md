# Prep AI v5.2

## Sidebar overlap: cause and fix
The goal card and the "MAIN" label / first nav item were separate Streamlit markdown elements. The card relied on its own bottom margin and the label on a top margin, and Streamlit wraps each markdown block in a container whose margin handling can pull the next element back under it. The fix removes the dependence on neighbouring margins: the logo and goal card are now one normal-flow HTML block (`display: flow-root`, no positioning, no negative margins), the nav label uses padding instead of margin, and the sidebar markdown wrapper margin is neutralised. Only `data-testid="stSidebar"`/`stMarkdownContainer` and our own `pp-*` classes are used.
Verified in the stand-in renderer (`scripts/preview_ui.py`), which deliberately wraps the sidebar blocks with a `-1rem` bottom margin. Not verified in real Streamlit (not installable in the build sandbox): please check the sidebar on your deployment.

## Editable goal
"Edit goal" (sidebar, dashboard, predictor) opens a dialog: exam (MDCAT/ECAT/NUMS/Class Test/Other), university, desired score, maximum score, exam date. Preset maxima are in `config.EXAM_PRESETS` (editable defaults, change them if an exam's format changes). Validation in `goals.validate`. Saved on the `students` row (new columns `goal_university`, `goal_score`, `goal_scale`; `exam_name`/`exam_date` are the existing fields the study planner also uses). Only these fields are written.

## Learning Games
Quick MCQ Challenge (10 q / 10 min) and Subject Sprint (10 q / 5 min), per subject or Mixed. Questions: question bank (own + tutor-shared) -> built-in starter set -> AI top-up, validated; never invented. Games are ordinary quizzes (history, mastery, streak, XP) plus one `game_results` row each. The Daily Challenge keeps its own page. A Flashcard Challenge was not added (Practice already has flashcards, and self-marked cards would make leaderboard points unverifiable).

## Leaderboard
Points = XP already stored in `daily_activity` (2/answered, 3/correct, 10/quiz, 20/perfect, daily bonus). One ledger, so nothing is counted twice. Periods: this week / all time. Ties: more correct, earlier sign-up, student id. Names: first name + last initial; email/phone-like names become "Student ABCD". Shows only students of this app database.

## Score Predictor
Same algorithm (`score_estimate.estimate`), on the goal's marks scale. Trend = running estimate per practice day (needs 20+ cumulative answers); subject accuracy; advice derived from real weak topics, due revisions and daily goal.

## Logo
`assets/`: original, full logo and icon (transparent, cut from the supplied image), 256px icon, favicon. Sidebar = icon + live "Prep AI" text (adapts to themes); login = full logo; page icon = favicon.
