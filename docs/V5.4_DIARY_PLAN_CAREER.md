# Prep AI v5.4: Mistakes Diary, calendar study plan, career wizard, tutor settings

Run `python -c "import migrations; print(migrations.migrate())"` or just start the app: migration 14 applies itself once (safe to re-run).

## What changed
| Request | What was built |
|---|---|
| Mistakes Diary | New page (Performance group) with a red count badge in the sidebar. Each mistake has **Teach me this mistake**: the AI tutor explains it (saved explanation if the AI is down). When the student presses **Next mistake**, or asks to be taught a different one, the taught mistake leaves the diary and the badge goes down by one. A mistake also leaves when the same question is later answered correctly. Nothing is deleted: `mistakes.resolved_at` is stamped. |
| Quick MCQ Challenge | 10 seconds per question (was 5). Rapid Fire is unchanged (60 s). |
| Game mistakes not in performance | A finished game round only adds XP, streak and the daily question count (`db.record_game_round`). It writes no quiz history, no mistakes, no mastery, nothing for the score estimate. Migration 14 removes mistakes that older versions copied from game rounds. |
| Study plan format | The saved plan is drawn as a weekly calendar (days across, hours down, coloured blocks, red "now" line, dashed "planned" blocks), with a start-time box, a Week tab per 7 days, a day-by-day list and an `.ics` download for Google/Apple/Outlook calendar. |
| Career Path Finder | A 9-step wizard from the Counselling Guide: A academic background, B interests and degrees, C skills and personality, D career goals, E university and affordability, F commitment, questions for the student's stream, a weighted comparison of up to 3 options (the guide's 7 criteria and weights), review and admission checklist. Progress is saved after every step. The old results (programs, eligibility, scholarships, accreditation, roadmap, evidence) still follow, now with a **My recommendation** card (3 degree options, universities to shortlist, 1 backup plan). |
| Tutor settings | Tutor sidebar now has **Settings**: AI model, quiz defaults that Create Quiz really starts from (difficulty, number of MCQs, time limit), accent colour and theme, account details. |

## Things to know
- Game rounds from v5.2/v5.3 still sit in History and mastery (they were stored as normal quizzes). Only their copied mistakes were removed.
- The career recommendation does not invent universities: it lists the ones the student typed. Degrees come from the student's own ranking, then from verified programs that match the stream. Family income is used for scholarship checks and is never saved.
- The sidebar count is drawn with CSS (button labels cannot hold HTML).
- Timed-game limits are unchanged otherwise: server clock decides, 0.8 s network allowance.
