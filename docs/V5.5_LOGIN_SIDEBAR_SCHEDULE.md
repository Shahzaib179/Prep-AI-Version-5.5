# Prep AI v5.5: login page, sidebar alignment, Today's Schedule

No database change. Replace the files and restart.

## Login page
Split screen like your reference: a dark form panel (Login / Sign up / Tutor sign up, underline fields, one primary button) beside a burgundy Prep AI panel with the logo mark,
"Welcome to Prep AI", the tagline (Adaptive Multi-Agent Learning Platform) and an illustration drawn for Prep AI (`login_ui.py`; the reference artwork was not reused).
"Sign up" and "Log in" switch the form on the same screen. Fields, labels, validation and the invite-code rule are unchanged. On screens under 900 px the brand panel is hidden and the form fills the card.

## Sidebar
Every item is one row: a fixed-width icon column, then the name, all left aligned, with the group headings on the same left edge. The CSS covers both ways Streamlit can place a button icon (beside or inside the label).

## Today's Schedule
One list, no "Study plan" / "Tutor assignments" headings. Every row starts with the icon of the sidebar tab it belongs to (`dashboard_data.schedule()["items"]`, each item names its `route`).
Study-plan sessions end with **Done**; pressing it saves the tick and turns the button green (pressing it again undoes it). Tutor assignments and quizzes show their due date and an **Open** button, because they are finished by doing them.

## Tests
`tests/test_dashboard.py` (4 new schedule tests), `tests/app_pages_smoke.py` (login screens, schedule rows, Done to green and back), `tests/ui_smoke.py`, all earlier modules.
Not run in the build sandbox: real Streamlit (so real browser rendering), Supabase/Postgres, live Groq.
